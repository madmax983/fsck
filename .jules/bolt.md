**[State History Command Parsing Allocation]**
**Learning:** `to_uppercase()` on user commands causes a heap allocation on every single keystroke/input. When only checking for the presence of static ASCII substrings, using `cmd.as_bytes().windows(len).any(|w| w.eq_ignore_ascii_case(b"PATTERN"))` is a safe, zero-allocation alternative that preserves existing logic entirely while avoiding string cloning or conversion overhead.
**Action:** Always prefer `eq_ignore_ascii_case` on byte-slice windows instead of `.to_uppercase().contains()` when scanning for fixed ASCII patterns in a potentially large or frequently accessed string, to eliminate allocations.
